# MaskSMP custom mask uploads

This folder is reserved for custom mask model and texture files uploaded for the MaskSMP website.

- Blockbench models: `.bbmodel`
- Mask textures: `.png`
- Optional level textures: `.png`

Keep this README so GitHub can track the folder even if a file picker hides the `.gitkeep` placeholder. Do not put passwords, private keys, or other secrets in this folder.
