06 / CUSTOM MASKS

Add a mask from Blockbench

Upload a cube-based Blockbench .bbmodel and its PNG texture. Optional tier textures let every level keep its own colour band. New masks are added to the Masks and Upgrading pages after you export and publish the config.

06

Mask abilities

These names and descriptions appear on the mask preview. Fill in what you know; defaults are used for empty fields.

Optional tier textures

Choose a separate PNG for any level that has a different band. If you leave one empty, the base texture will be used for that level. Existing MaskSMP tier textures are not changed.

Keep each model under 2 MB and each texture under 1 MB. All mask models and textures together are limited to 10 MB so the exported config remains reasonably portable. Files are stored in site-config.json, not uploaded to a server.
